ABOUT AL SAHAB AL RASID

AL SAHAB AL RASID TRAD. & CONT. CO. L.L.C. (ASAR) is an established construction and engineering contracting entity registered and operating in the Sultanate of Oman. The company specializes in executing civil construction, healthcare facility development, infrastructure, heavy concrete structures, mechanical and electrical engineering, pipeline works, and certified technical manpower supply.

Supabase Cloud PostgreSQL Database Setup Guide

Follow the 2 simple steps below to connect your real Supabase backend project or update your keys. All tender and quotation submissions from `#contact-form` are automatically inserted into table quotation_requests.

1 Connect Your Supabase Project Credentials

Found in Supabase: Project Settings → API → Project URL
Found in Supabase: Project Settings → API → Project API keys (anon / public)

2 1-Click PostgreSQL Schema for Supabase SQL Editor

Open your Supabase Dashboard → SQL Editor → Paste this script and click RUN: 

-- 1. Create table for quotation and tender requests
CREATE TABLE IF NOT EXISTS public.quotation_requests (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    ref_code TEXT NOT NULL,
    name TEXT NOT NULL,
    company TEXT,
    email TEXT NOT NULL,
    phone TEXT NOT NULL,
    service TEXT NOT NULL,
    location TEXT,
    tender_value TEXT,
    message TEXT,
    status TEXT DEFAULT 'new'
);

-- 2. Enable Row Level Security (RLS)
ALTER TABLE public.quotation_requests ENABLE ROW LEVEL SECURITY;

-- 3. Allow anonymous visitors to submit quotation requests from website
CREATE POLICY "Allow public insert to quotation_requests" 
ON public.quotation_requests 
FOR INSERT 
WITH CHECK (true);

-- 4. Allow reading quotation requests for the portal
CREATE POLICY "Allow select on quotation_requests" 
ON public.quotation_requests 
FOR SELECT 
USING (true);
